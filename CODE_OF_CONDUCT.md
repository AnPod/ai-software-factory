# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback about the work, and make it easy for anyone to take part, whatever their background or level of experience. Harassment, personal attacks and sharing someone's private information are not accepted.

## Reporting

If someone's behaviour in this project's issues, pull requests or discussions worries you, contact the maintainer, AnPod, through GitHub. Reports are handled privately. For security problems, use private vulnerability reporting as described in [SECURITY.md](SECURITY.md).

The maintainer may edit or remove comments, commits and issues that break this code, and may block people who keep doing so.
